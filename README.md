# 🧪 Testes Exploratórios — AliExpress

Projeto prático de QA com foco em testes exploratórios em uma aplicação real de e-commerce.

## 🎯 Objetivo

Validar funcionalidades principais do AliExpress, observando comportamento do sistema, consistência dos fluxos, usabilidade e possíveis problemas durante a navegação.

## 🔍 Funcionalidades testadas

- Busca vazia
- Busca com caracteres especiais
- Busca com texto extenso
- Cliques rápidos no carrinho
- Filtros combinados
- Navegação após adicionar produto ao carrinho
- Carrinho sem autenticação
- Limite de quantidade por produto

## 🛠️ Ferramentas utilizadas

- Navegador web
- Testes manuais
- Documentação em Markdown

## 📌 Resultado geral

Durante os testes realizados, o sistema apresentou comportamento estável e consistente. Não foram identificadas falhas críticas, apenas observações relacionadas à relevância dos resultados de busca em entradas incomuns.

## 👩‍💻 Sobre

Projeto desenvolvido como parte dos estudos em QA, com foco em prática real, documentação e análise de comportamento de sistemas web.
